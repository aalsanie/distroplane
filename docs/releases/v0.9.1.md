# Distroplane v0.9.1

This stable maintenance release strengthens the Distroplane CLI distribution and recovery paths.

## CLI and safety

- Adds guided configuration and high-level publication, status, resume, and diagnostics entry points with explicit publication approval.
- Keeps digest-bound provider binaries available for recovery across CLI upgrades.
- Tightens immutable run state, package selection, credential discovery, and validation.

## Release distribution

- Adds reproducible Linux, macOS, and Windows unified archives containing the CLI and four provider executables.
- Publishes exact release metadata, checksums, embedded executable digests, and GitHub build attestations.
- Adds a verified direct Linux installer with offline installation, atomic version switching, and corruption/rollback checks.
- Proposes official Homebrew tap formula updates from published assets, gated on review and native Homebrew CI.

## Availability and verification

The GitHub release contains standalone executables and unified archives; the official Homebrew formula is available **only after** its independently tested tap PR is merged. Windows MSI and public WinGet catalog installers are not part of this patch release.

See [release verification](../release-verification.md) for checksum validation and installation requirements. A checksum published alongside an archive is not an independent signing identity.
