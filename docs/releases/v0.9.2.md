# Distroplane v0.9.2

This maintenance release adds native Windows MSI distribution to the existing standalone executable and unified-archive delivery paths.

## Windows installation

- Adds per-machine MSI installers for Windows x64 and ARM64.
- Each MSI contains the Distroplane CLI and the npm, SDKMAN, Homebrew, and WinGet providers.
- Supports install, in-place upgrade, repair, and uninstall with machine PATH registration.
- Native Windows CI verifies provider startup, upgrade behavior, and preservation of user-owned run state.

## Integrity and distribution

- Release MSI files are built from verified unified archives and accompanied by `MSI-SHA256SUMS` and GitHub Actions provenance attestations.
- Windows MSI files in this release are **not Authenticode-signed**; Windows SmartScreen and enterprise policies may warn or block installation.
- Checksums and build attestations do not establish a Windows-trusted publisher identity.
- Existing Linux, macOS, and Windows standalone and archive distribution remains available.
- Homebrew tap updates continue through a separately reviewed, tested proposal.
- The public WinGet catalog listing is not yet available and depends on Microsoft's review and acceptance.

See [release verification](../release-verification.md) and [Windows installer details](../windows-installer.md) for verification and installation guidance.
