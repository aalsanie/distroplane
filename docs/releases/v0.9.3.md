# Distroplane v0.9.3

This maintenance release updates the Go toolchain used to build Distroplane's native CLI and providers and tightens release artifact verification.

## Security and build integrity

- Builds the CLI and four bundled providers using Go 1.27.3, incorporating the Go 1.27 security patch updates.
- Aligns the Go version used by CI, release workflows, CodeQL, GitHub Action smoke tests, and Maven integration tests.
- Verifies the embedded Go compiler version in every executable for Linux, macOS, and Windows on AMD64 and ARM64.
- Rejects release executables with unexpected command or module identity, operating system, architecture, CGO setting, or untrimmed build paths.
- Rejects release packaging or verification if the claimed Go version differs from the approved toolchain.

## Distribution

- Retains the existing CLI and provider protocol, publication behavior, immutable planning, and journal recovery contracts.
- Continues to ship the same native executable, unified archive, checksum, provenance, and Windows MSI asset formats.
- Windows MSI installers remain unsigned and may trigger SmartScreen or managed-device restrictions; checksums and attestations do not establish an Authenticode-trusted publisher.
- Homebrew tap updates continue through the separately reviewed published-asset verification process.

See [release verification](../release-verification.md) for installation and integrity checks.
